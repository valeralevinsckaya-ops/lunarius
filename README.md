# Спидометр совместимости

Сайт с расчетом совместимости пары по натальным картам (синастрия). Шкала от -10 до +10, показатель отдельно для каждого партнера, общая тенденция, шесть сфер отношений и главные аспекты между картами.

## Что внутри

| Папка / файл | Назначение |
|---|---|
| `server.js` | сервер: отдает сайт, ищет города, считает совместимость |
| `lib/chart.js` | натальная карта: планеты, Асцендент, MC, дома Плацидуса |
| `lib/synastry.js` | синастрия: аспекты, веса, шкала -10..+10, сферы |
| `lib/texts.js` | тексты разбора (можно править без программиста) |
| `lib/report.js` | собирает итоговый ответ |
| `lib/natal.js`, `lib/natal-texts.js` | натальная карта одного человека: аспекты внутри карты, тексты планет в знаках и домах |
| `public/natal.html`, `public/natal.js` | страница «Натальная карта» (/natal) с колесом карты |
| `docs/` | статьи блога и данные Вордстата |
| `data/cities.json` | около 28 тысяч городов на русском с координатами и часовыми поясами (GeoNames, CC BY 4.0) |
| `data/calibration.json` | калибровка шкалы на 20 тысячах случайных пар |
| `public/` | сайт: `index.html`, `app.js`, картинки знаков |
| `design/Main.dc.html` | исходник дизайна, из него собирается `public/index.html` |

## Как это работает

1. Город превращается в координаты и часовой пояс из `data/cities.json`. Исторические смены поясов и летнего времени учитываются (база IANA через библиотеку luxon).
2. Положения Солнца, Луны и планет считаются библиотекой astronomy-engine (лицензия MIT). Если время рождения указано, добавляются Асцендент и дома Плацидуса.
3. Ищутся аспекты между картами: соединение, секстиль, квадрат, трин, оппозиция. У каждой пары планет свой вес, гармоничные аспекты дают плюс, напряженные минус.
4. Сырые баллы переводятся в шкалу -10..+10 по калибровке: 0 означает типичную пару, около 5% пар получают +5 и выше.
5. Данные пользователей не сохраняются: расчет идет в памяти, ответ сразу уходит в браузер.

## Запуск на своем компьютере

Нужен Node.js версии 18 или новее.

```
npm install
npm start
```

Сайт откроется по адресу http://localhost:3000

## Размещение на хостинге

Подойдет любой российский облачный хостинг с поддержкой Node.js-приложений (например, Timeweb Cloud, Selectel, Яндекс Облако). Общий порядок:

1. Загрузить проект (архивом или через GitHub).
2. Команда установки: `npm install`, команда запуска: `npm start`.
3. Порт приложение берет из переменной окружения `PORT` (по умолчанию 3000).
4. Привязать домен и включить HTTPS в панели хостинга.

## Как менять

- Тексты разбора: `lib/texts.js`, без буквы «ё» и без длинных тире.
- Веса планет и аспектов: `lib/synastry.js`. После изменения весов обязательно пересчитать шкалу: `npm run calibrate`.
- Статьи блога: правки в Google Doc, затем выгрузка в `docs/blog-articles-edited.html` и `python3 scripts/build_blog.py` (собирает `public/blog/`).
- Счетчик Метрики: `design/metrika.html`, подставляется во все страницы при сборке (в `natal.html` и `privacy.html` вставлен вручную).
- Дизайн: правится в `design/Main.dc.html`, затем `npm run build:design` (нужен Python 3) пересобирает `public/index.html`.
